==============================
  Daily Report Tool
==============================

[Usage]
0. 重跑时若总表已有目标日数据，会先删除该日旧行再重新导入（覆盖更新）。
1. 确保两个 Excel 已在固定位置：
   - 有效表：本项目根目录，如 9月-信息流【深圳有效表】.xlsx
   - 投放数据：E:\AI项目\深圳信息流报表-cursor\ 根目录，
     如 9月信息流投放数据（深圳）.xlsx（只读，脚本不修改该表）
2. 双击 run.bat
3. 脚本会：
   - 登录 CRM，导出 信息流线索池（昨天数据）
   - 登录 CRM，导出 建档客户池-片区（昨天数据，三级渠道筛选）
   - 处理数据并更新有效表（原地覆盖保存）
   - 从 cursor 项目投放数据只读读取账户消费，写入有效表消费 sheet
   - 将 CRM 导出原表复制到「完成」文件夹存档

[补跑某天数据]
- 默认处理「昨天」。要处理指定日期，命令行传参：
    python daily_report.py 2026-09-02
- 连续补两天：直接依次传不同日期运行即可（有效表在项目根目录原地更新）

[First-time setup]
pip install openpyxl msoffcrypto-tool playwright pywin32
playwright install chromium

[Requirements]
- 内网 CRM 可访问（192.168.10.16:8899）
- 投放数据由「深圳信息流报表-cursor」项目维护，本脚本只读

[Output]
- 有效表：本项目根目录原地覆盖（如 9月-信息流【深圳有效表】.xlsx）
- 完成/ 文件夹：CRM 信息流线索池、建档客户池原表存档

[Notes]
- 日期默认「昨天」；可通过命令行参数指定
- 月份自动匹配：9 月跑 9 月文件，换月后把新文件放到对应根目录即可
- 平台筛选：腾讯广点通, 百度, 惠州广点通, 三方 (excluding 香港)
- 三方数据(3)：非重复；非「-线下」须建档时间=目标日；「-线下」仅须记录时间=目标日（平台按创建时间统计）
- data/ 文件夹已弃用，仅保留历史备份
